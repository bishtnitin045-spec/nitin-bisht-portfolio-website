# Nitin Bisht Portfolio Website

This is a static website made with HTML, CSS, and a small JavaScript file. It is ready to preview locally or publish with GitHub Pages.

## Preview

Open `index.html` in a browser.

## Update

- Edit the content and links in `index.html`.
- Adjust colors, spacing, and mobile layouts in `styles.css`.
- `script.js` controls the small-screen navigation and footer year.

## Publish with GitHub Pages

1. Put these website files in a GitHub repository. Keep `index.html` at the repository root.
2. In that repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the `main` branch and `/(root)`, then save.
4. GitHub will show the public site address in the Pages settings after deployment.

GitHub Pages publishes static files from a repository. The site and its contact details will be publicly visible once published.
